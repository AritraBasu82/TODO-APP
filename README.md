# 📝 Modern React To-Do List

A clean, responsive, and beautifully styled To-Do list application built from scratch using React and Vite. 

**https://todo-app-tawny-omega-21.vercel.app/**

## ✨ Features
* **Add Tasks:** Quickly add new items to your daily list.
* **Mark as Complete:** Check off tasks with a strikethrough effect.
* **Delete Tasks:** Remove items you no longer need.
* **Modern UI:** Features a smooth gradient background, soft shadows, hover animations, and a perfectly centered layout.
* **Empty State Handling:** Displays a friendly message when all tasks are cleared.

## 🛠️ Technologies Used
* **React** (useState, JSX)
* **Vite** (Next-generation frontend tooling)
* **CSS3** (Flexbox, custom scrollbars, animations)
* **HTML5**
